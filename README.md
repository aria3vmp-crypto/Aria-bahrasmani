🐛 Bug Reports

Software is constantly evolving, and unexpected problems can sometimes occur.

If you discover a bug, problem, compatibility issue, or unexpected behavior, please report it through the appropriate project channel.

A useful bug report may include:

- Project name
- Software version
- Operating system
- Hardware information when relevant
- Description of the problem
- Steps to reproduce the issue
- Error messages or screenshots when available

Detailed reports make problems easier to investigate and fix.
